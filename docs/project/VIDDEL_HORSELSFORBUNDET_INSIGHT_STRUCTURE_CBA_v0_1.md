# Innsikt for Hørselsforbundet — strukturell CBA v0.1

Status: Godkjent starteksempel for samtale

Eier: Thomas

Relatert GitHub-sak: #305

Interaktivt samtalegrunnlag: `public/vis/raw/viddel-horselsforbundet-insight-conversation-v0_1.html`

Sist oppdatert: 2026-08-05

## 1. Rolle og kildegrense

Flaten er en syntetisk samtaleprototype. Den skal brukes til å undersøke om
Hørselsforbundet forstår og ser nytte i denne typen aggregert innsikt.

Den kanoniske brukersyntesen beskriver aggregert samfunnsinnsikt som en styrket
kandidat, men parkerer ekstern verdi til samtykke og nytte er avklart. CBA-en
er derfor ikke dokumentasjon på at datagrunnlaget, analysen eller verdien
allerede finnes.

## 2. Godkjent struktur

Én lineær brief viser:

1. tydelig syntetisk sannhetsgrense
2. rangert liste over hva mennesker ber om hjelp med
3. aggregerte signaler om hvor de fortsatt står fast
4. åpne spørsmål det kan være relevant å undersøke
5. metode- og datagrense

Et enkelt periodebytte er eneste interaksjon. En egen tilstand stopper
rangeringen når eksempelgrunnlaget er for lite.

## 3. Bruk nå

Starteksempelet brukes som samtalegrunnlag før copy-, visuell- eller
implementeringsport åpnes.

Samtalen støttes av fem spørsmål:

1. Hva kunne Hørselsforbundet brukt dette til?
2. Hvilken del gir mest verdi?
3. Hvilken handling eller beslutning kan følge?
4. Hva må være kjent for at innsikten skal oppleves troverdig?
5. Hva bør aldri vises eller samles inn?

## 4. Sannhetsgrense

- Alle tall og signaler er syntetiske.
- Ingen reelle samtaler eller personopplysninger brukes.
- Flaten viser ikke enkeltbrukere, sitater eller rå samtaler.
- Materialet er ikke statistikk eller dokumenterte brukerfunn.
- Ingen analysepipeline, samtykke, anonymisering eller organisasjonstilgang er
  besluttet.
- Avlastning, økonomisk effekt og betalingsvilje skal ikke framstilles som
  dokumentert.

## 5. Ikke besluttet

- endelig UX-copy eller visuell utforming
- reell datakilde og analysemetode
- terskler for små grupper
- samtykke-, personvern- og tilgangsarkitektur
- eksport eller rapportering
- produktintegrasjon

## 6. Neste port

Bruk starteksempelet i samtaler. Funn, usikkerhet og forslag føres tilbake til
#305 før strukturen revideres eller neste port åpnes.
